# Smart-Browser 0.2.1

The first published release of the 0.2 line.
It is 0.2.0 with one correction, so everything in [the 0.2.0 notes](v0.2.0.md) applies, including the upgrade steps from 0.1.0.

0.2.0 was tagged but never published: its committed OpenAPI contract still said 0.1.0, and CI failed on the release commit after the tag was pushed.
The tag stays where it is rather than being moved, and this release carries the fix.

## Fixed

- **The OpenAPI contract names the right version.**
  `packages/shared-types/openapi.json` embeds the release version, and nothing regenerated it on a version bump.

## Under the hood

- `make version-set` now regenerates the OpenAPI contract and relocks `apps/api/uv.lock`, the two files besides the manifests that record the version.
- `make check` fails when either has fallen behind, through `make openapi-check` and `make version-check`.
  CI runs the same targets, so a release can no longer pass locally and fail after it is tagged.
